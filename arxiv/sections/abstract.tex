This document is both the template and its manual. It keeps the page geometry and type sizes of NeurIPS, so a conference submission moves to arXiv without reflowing, and adds a first page with authors, contribution notes, resource links, and an abstract box. Every element a machine learning paper typically needs is shown in context: a teaser figure, callout boxes, figures, tables, plots, algorithms, theorems, code listings, prompts, review comments, references, and an appendix with its own table of contents.
